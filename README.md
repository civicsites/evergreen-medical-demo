# Evergreen Family Medicine & Psychiatry (Demo)

Fictional demonstration website built by **Civic Sites Studio** to showcase medical practice web design for prospective clients.

**This is not a real healthcare provider.** All providers, contact details, and scheduling flows are simulated. No patient data is collected.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS
- [Lucide React](https://lucide.dev) icons

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Pages

- Home, Family Medicine, Psychiatry, Telehealth, Our Providers, New Patients, Appointments (demo scheduler), Contact
